# Upstream notices for generated Sail models

The HOL Light definitions in `generated/` translate external Sail model
and library bodies. Their upstream notices are preserved below; source
paths in the generated definitions identify the bodies used. These
notices concern the upstream material, not a change to the license of
the hand-written exporter or proofs.

The revisions match [ci/versions.env](ci/versions.env). When changing a
source revision or adding translated library code, check the notices
again and update this file along with the generated models.

| Generated material | Upstream repository and revision | Notice source |
| --- | --- | --- |
| `arm-*.ml` | `rems-project/sail-arm`, `f5bf6c3a2b5df8c7f6f9d3572825ff074e0c6b7c` | `arm-v9.4-a/LICENSE`, [AArch64](#aarch64) |
| `rv32.ml`, `rv32-control.ml` | `riscv/sail-riscv`, `cd3f185e3a40cd402632d78a2bc213d62ae6f753` | `LICENCE`, [RISC-V](#risc-v) |
| `x86-*.ml` other than `x86-rems-*.ml` | `shina-lab/sail-x86`, `1829cb6ecc5f924b0fd920582953a2402357a12a` | `LICENSE`, [shina x86](#shina-x86) |
| `x86-rems-*.ml` | `rems-project/sail-x86-from-acl2`, `0c6c023dccc7c20d8d9dbfc481f01d9bb49d62bf` | `model/LICENSE`, both [REMS and ACL2 x86](#rems-and-acl2-x86) notices |
| Translated Sail helpers in any model | `rems-project/sail`, `3df54034910b31a1e00d948ee965b2e9603d68e0` | `LICENSE` and library source headers, [Sail library](#sail-library) |

The translated library sources named in the current snapshots are
`lib/core/corelib.sail`, `lib/arith.sail`, `lib/flow.sail`,
`lib/generic_equality.sail`, `lib/option.sail` and `lib/vector.sail`.
Their shared source notice is retained after Sail's repository license.
The model licenses also cover model-local helpers, such as each model's
own `prelude.sail`; those are not Sail compiler-library files.

The notice bundle is shared rather than repeated in every generated
file. Keep it with the snapshots when redistributing them.
