# HANDOFF: proof of DecompressBranchless<char*> (stream BRANCHLESS)

Goal: prove `SNAPPY_DECOMPRESS_BRANCHLESS_CHARP_GCC12_O2_IMAGE_SUBROUTINE_{SAFE,CORRECT}`
exactly as stated in `arm/proofs/snappy/gcc12_O2/decompress_branchless_spec.ml`.
The proof file is generated by `arm/dev/branchless/assemble.py`. The files in `arm/dev/branchless/` are the
development sources (development scripts, not proofs of the repository).

## Method (DESIGN 7d, refined)

Cut points with a measure (`ENSURES_MEASURE_INDUCT`, common/ensures_measure.ml),
three kinds of state (strings in `dbstmt.ml`, `db_R`):

- TAG (PC 0x6140 = pc+24896 if w = 2, 0x61f0 = pc+25072 if w = 1): next tag at h,
  X19 = ip + h + 1, X27 = word_zx(EL h inp), X8 = dl. Measure 2(li-h)+1.
- J (0x61e4 = pc+25060, join4 after a tag, X26 = word w): measure 2(li-h)+2.
- E (0x6238 = pc+25144, join7, X22 = ip + h + 1): measure 0.

Common invariant `db_common`: SP = X29 = sp-240, X20 = base, X21 = lim-64,
X23/X24 = &dsrc/&dl, X28 = word op, input `bytelist(ip,li) = inp`, output
`bytelist(base,op) = ob`, deferred `bytelist(dsrc,dl) = db`, the frame slots, rw,
ev, events `?e2. events = APPEND e2 e /\ memaccess_inset e2 RD WR`.
Static `db_static`: `snappy_steps k m (inp,out) = SOME(SUB_LIST(h,li-h) inp, APPEND ob db)`,
lengths, dl <= 64, the three facts about dsrc (nonoverlap with output at op and
with the stack, memrange(dsrc,64) SUBSET RD).
Frame of all segments = the spec's frame C (idempotent).

Each segment is a lemma `!ghosts. G /\ static /\ bounds ==> ensures arm pre
(\s. Q s \/ ?n'. n' < N /\ R n' s) C` (`db_lemma`, `db_tag_leaf extra`).

Key tools (in `fin.ml`, `dbt.ml`, `pat.ml`):
- `DB_FLUSH` (flushp.ml): MemCopy64 as the fast path calls it, with
  bytelist(base,op) = L, bytelist(src,dl) = D giving bytelist(base,op+dl) =
  APPEND L D and events in RD/WR, frame = clauses of C. PROVED.
- `DB_RUN_TAC ~rws ~folds stops`: single-step bstep with branch decision
  `DB_DECIDE_TAC` (signed compares via ival, `DB_IVAL_CONV`), until PC in stops.
- `DB_TO_TAC which n ghosts`: finish at a cut point (1 = J, 0 = TAG, 2 = E).
  `DB_REG_TAC` proves each register/memory fact up to `DB_NORM_CONV`
  (normal form of word sums and num arguments), `DB_WORD_EQ_TAC` (ival /
  mod 2^64), `DB_EVENTS_TAC` (event subsets by base + offset arithmetic).
- Pattern copies: `DB_SRC_TAC` (q = 16 bytes at op'-K), `DB_PAT_STEP_TAC`
  (SNAPPY_COPY_PATTERN_STEP or the byte variant DB_COPY_PATTERN_STEP_BYTES),
  `DB_TRUNC_TAC`.
- Static transitions (pure): DB_STEP_LIT, DB_STEP_COPY_DEFER, DB_STEP_PATTERN,
  DB_STATIC_FLUSHED. Table: SNAPPY_LMO_TABLE (kLengthMinusOffset, checked).

## Notes from the RawUncompress(Source*) proof (later)
- The mask bytes of LeftShiftOverflows are read by `ldrb w0, [x19, x22]` at
  `word_add (word k) (word_add (word pc) (word 32192))`; bstep does not carry
  facts at such addresses, so they are added just before that instruction
  (RU_MASK_NORM_TAC as ~norm, only at PC 0x50b8; adding them after every step
